# MaxxHome Website

Website resmi MaxxHome Internet Service untuk menampilkan paket internet rumah, keunggulan layanan, cakupan area, FAQ, dan pendaftaran melalui WhatsApp.

## Fitur

- Desain responsif untuk desktop dan perangkat mobile
- Informasi paket 30–100 Mbps
- Formulir cek area terhubung ke WhatsApp
- FAQ interaktif
- Menu mobile dan animasi ringan

## Menjalankan secara lokal

Buka `index.html` langsung di browser, atau jalankan server statis lokal dari folder proyek.
